# موارد مُتقِن — مصحف المدينة

خطوط صفحات مصحف المدينة النبوية (رسم مجمع الملك فهد لطباعة المصحف الشريف — خطوط QCF V2)
وبيانات مواضع الكلمات لكل صفحة من صفحات المصحف الـ٦٠٤.

ينزّلها تطبيق **مُتقِن** تلقائيًا عند أول فتح لتبويب المصحف (مرة واحدة)،
ثم يعمل المصحف بلا إنترنت.

- `mushaf/fonts/{n}.woff2` — خط الصفحة `n` (رسم الصفحة حرفًا بحرف)
- `mushaf/pages/{n}.json` — كلمات الصفحة وسطورها وأرقام آياتها
- `mushaf/index.json` — فهرس الأجزاء والأرباع

المصدر: أصول مجمع الملك فهد كما تتيحها Quran.com (qurancdn).
